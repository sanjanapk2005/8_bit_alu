# **8-Bit Arithmetic Logic Unit (ALU) Using Verilog**


## **Project Overview**

Designed and simulated an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL in Xilinx Vivado 2025.1.

The ALU performs arithmetic and logical operations on 8-bit input operands based on the selected control signals.

## **Tools and Technologies**

- Verilog HDL

- Xilinx Vivado 2025.1

## **Project Files**

- alu_src_code.v – Main ALU design module.

- alu_tb.v – Testbench for functional verification.

## **Design and Verification**

- The ALU functionality is verified using a Verilog testbench through simulation in Xilinx Vivado.

## **Key Learning Outcomes**

- RTL design using Verilog HDL.

- Understanding arithmetic and logical operations.

- Functional verification using testbenches.

- Simulation and debugging using Vivado.
